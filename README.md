One word, the first that comes to mind. This program writes it to
`/output/entry.txt` — nothing else, no explanation, no second draft.
Run it with Node 22: `node main.ts`.

The word is **psithurism**: the sound of wind whispering through trees —
rare enough to surprise, vivid enough to picture at once, and its soft
sibilants sound like the thing itself.
